# ÍNDICE — mapa de la memoria de la empresa (Second Brain de FPL Business)

Aquí está qué tema vive en qué archivo. Cada archivo nuevo se anota
aquí; si no, nadie lo encuentra.

| Tema | Dónde |
|------|-------|
| Reglas de trabajo (constitución) | `CLAUDE.md` |
| Instalación del sistema (se usa una sola vez) | `INSTALAR.md` |
| Preguntas abiertas para la próxima reunión | `PENDIENTES.md` |
| Estado del trabajo: hecho, pendiente | `ESTADO.md` |
| Decisiones con fecha y motivo | `DECISIONES.md` |
| Traspasos entre sesiones | `traspasos/` |
| Estado de la entrevista «Segundo cerebro» | `estado-entrevista.md` (lo crea la entrevista) |
| Entrevista «Segundo cerebro» (skill) | `.claude/skills/entrevista-segundo-cerebro/` |
| Traspaso al final de la sesión (skill) | `.claude/skills/traspaso/` |
| Crear agentes de IA (skill y plantillas) | `.claude/skills/crear-agente/` |
| Ajustes: bloqueo de comandos peligrosos, aviso al iniciar sesión | `.claude/settings.json`, `.claude/hooks/` |
| Guía completa de instalación (programas, conectores, prompts, preguntas) | `GUIA.md` |
| Plantilla del espacio de dirección (repositorio aparte, solo dirección) | `plantilla-direccion/CLAUDE.md` |

*Las demás entradas nacen en la entrevista: el asistente anota aquí
cada archivo nuevo.*
