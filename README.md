# Second Brain de FPL Business — memoria de la empresa

Conocimiento, procesos y reglas de la empresa para el asistente de IA
(Claude). Todo el equipo trabaja con la misma memoria.

- **Primera vez:** abre una sesión de Claude Code con este repositorio y
  escribe: `Lee INSTALAR.md y sigue las instrucciones.`
- **Después:** `/entrevista-segundo-cerebro` para construir la memoria,
  `/traspaso` al final de cada sesión, `/crear-agente` para agentes.
- **Mapa de todo:** `INDICE.md`. **Reglas:** `CLAUDE.md`.

## ¿Quieres tu propio Second Brain?

Botón verde **Use this template → Create a new repository** (elige tu
organización y **Private**). Luego conecta el repositorio en
https://claude.ai/connect-github, abre https://claude.ai/code con él y
escribe `Lee INSTALAR.md y sigue las instrucciones.` La guía completa
paso a paso está en `GUIA.md`.
